# Luca Zanotti Academic Website

This is a simple static academic website inspired by clean economics job-market websites.

## Files

- `index.html`: homepage
- `research.html`: research page
- `cv.html`: CV page
- `data.html`: data/code page
- `style.css`: shared style file
- `images/profile.jpg`: replace with your photo
- `files/cv.pdf`: replace with your CV

## How to publish with GitHub Pages

1. Create a GitHub repository named `yourusername.github.io`.
2. Upload all files in this folder to the repository.
3. Go to Settings > Pages.
4. Set source to the main branch.
5. Your website will appear at `https://yourusername.github.io/`.

## Things to edit first

- Replace `your.email@northwestern.edu`.
- Replace placeholder links for Google Scholar, GitHub, LinkedIn.
- Replace profile photo and CV.
